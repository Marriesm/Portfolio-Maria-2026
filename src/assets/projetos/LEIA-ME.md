# Prints dos projetos

Solte aqui as imagens de cada projeto. Elas aparecem sozinhas no carrossel da seção Projetos.

O nome do arquivo diz de qual projeto ela é: `<slug>-<número>.<ext>`

| Projeto | Exemplo de nome |
| --- | --- |
| Ativação | `ativacao-1.png` |
| Farol das carteiras | `farol-1.png`, `farol-2.png` |
| Camada de dados histórica | `dados-historicos-1.png` |
| Esteira de onboarding | `onboarding-1.png` |
| Reuniões com IA | `reunioes-ia-1.png` |
| Régua de cobrança | `cobranca-1.png` |
| Screenmatch (Java) | `screenmatch-1.png` |
| IA de atendimento (n8n) | `ia-atendimento-1.png` |

- Formatos: png, jpg, webp, avif ou gif. A ordem segue o número.
- Melhor proporção: 16:10 (ex.: 1600×1000). A miniatura mostra o topo da tela; ampliada, a imagem aparece inteira.
- Legendas e o texto da barra de endereço ficam em `src/data/portfolio.ts` (`captions` e `mediaLabel`).
- Cuidado com dados de clientes: borre nomes, telefones e valores antes de publicar.
